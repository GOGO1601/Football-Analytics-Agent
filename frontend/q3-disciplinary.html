Reading this chart

  • Each bubble = one team-season. Only seasons where fouls, yellow cards, and red card data exist are included.
  • Bubble size = Avg red cards per game — larger bubbles received more red cards.
  • X-axis = disciplinary metric (switchable between fouls and yellow cards).
  • Y-axis = final points total for that season.
  • Hover any bubble for team, season, league, and full disciplinary stats.
  • Colour mode can be switched between league identity or yellow/red card intensity (sequential scale).
  • A dashed trend line shows the overall correlation direction across all visible data.
